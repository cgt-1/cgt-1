## 🔬 Things I've Built

A few projects I've worked on while learning:

### 💳 Credit Score Classification
Explored how machine learning can be used to classify credit scores using a messy real-world-style dataset.

Worked on data cleaning, preprocessing, feature engineering, Random Forest and XGBoost models, evaluation, and eventually model deployment.

### 🎵 Song Recommendation System
Built a content-based recommendation system exploring song similarity using audio features, genres, text features, and cosine similarity.

### 🌡️ Delhi Temperature Forecasting
Experimented with a stacked LSTM model to predict the next day's temperature using the previous 30 days of weather data.

### 📈 Stock Price Forecasting
Explored LSTM-based time-series forecasting using historical stock price data.

### 👁️ Computer Vision Projects
Worked with CNN-based image classification and object detection, along with experiments involving autoencoders and generative models.

### 🌐 Web Development
Built websites using HTML, CSS, and JavaScript as part of my exploration outside of Data Science.
